# autoCraft explainer — storyboard

~112 s, 1920×1080, 30 fps. Built entirely from scripts in this folder (Blender for 3D, Python for the 2D UI frames),
so every shot can be re-rendered after a change to the bot. The video is silent; a licensed song is added in the edit.

**Show, don't tell.** The bot does things on screen; text is limited to the panel the viewer will actually use,
short chapter tags ("1 · Pick", "2 · Plan" …) and the end card. No narration.

## Art direction
- Stylized voxel world with original pixel textures (generated by `kit.py`, not Mojang's), soft sun and sky
  lighting, gentle depth of field, bloom on anything the bot "thinks" with.
- Colour language: **redstone red** = the bot (its status light, the logo); **cyan** = what the bot sees and plans
  (scan rings, path ribbon, plan tree links); **amber** = the target it picked; **green** = done.
- The bot: a blocky player in a teal shirt with a small red status light over its head — red idle, green working.
- Camera: slow, motivated moves (dolly, orbit, crane); cuts land on the beat of the music.

## Sound
None in the render. The music (a Newgrounds track chosen by the author, licence permitting) is laid in at the edit.

## Rendering
Needs [Blender 5.x](https://www.blender.org/download/) (the scenes use Eevee and 5.x APIs) and Python 3:

```
pip install pillow numpy imageio-ffmpeg
python docs/video/render_all.py
```

That makes the Tasks panel frames for shot 2, renders all eight shots into `docs/video/renders/` (ignored by git) and
cuts `docs/video/autocraft-explainer.mp4`. It finds Blender on PATH, in the usual install folders or via
`--blender PATH`; it is resumable (stop it and run it again, finished frames are kept) and prints an estimate as it
goes. 3,435 frames at 1920×1080: roughly 3 to 6 s a frame on a laptop's integrated graphics, far less on a gaming GPU.

- `--samples 12` halves the time for slightly grainier soft shadows (the default is 24).
- `python docs/video/render_all.py shot6_city` renders one shot; `--preview --frames 1,150` makes quick half-size
  stills into `renders/preview/`.
- Pieces: `ui_frames.py <dir>` (panel frames; shot 2 reads them from `AUTOCRAFT_UI`), `blender/render.py` (one shot:
  `blender -b --factory-startup --python blender/render.py -- <shot> <dir> [preview] [frames=…] [samples=N]`),
  `edit.py <renders> <out.mp4>` (crossfades, chapter tags, fades).

`previews/` has stills of every shot rendered at full quality, and clips of what was already rendered.
